The two int editors write what they know on the element, not only in prose:
`min`/`max` (the ends of the live allowed set where there is one, the
catalogue's own bound where there is not), `pattern`, and a `<datalist>` of the
allowed values wired by `list`. The year field measured on a phone answered
`min: null, max: null, list: null` while the refusal beside it named the range,
so nothing that reads a field instead of tapping it — autofill, assistive tech,
a walker — could tell a bounded field from a free one. The list is attached only
where the set is listable, and the bound is stated, never enforced.

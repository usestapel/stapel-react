The rating badge reads number-first, like the reference

0.8.2 drew the glyphs before the number at every rung. The reference writes
"4.3 *", and the owner ruled for that form: score, stars, dot, count — and the
same order at every rung, so a card that resizes never reshuffles the badge
under the eye. Only the glyph count and the length of the words change as the
column narrows.
